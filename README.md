# QuantData-Async: 高并发 A 股量化数据同步与智能化清洗系统

**QuantData-Async** 是一个专为量化交易设计的 A 股全市场数据同步管线（Data Pipeline）。该项目不仅实现了基于 `asyncio` 的多源数据高并发抓取，还创新性地引入了 **LLM（大语言模型）** 对非结构化的主营业务数据进行语义对齐与标准化分类。

---

## 🚀 核心技术亮点

### 1. 自研异步任务调度引擎 (`AsyncScheduler`)
* **并发控制**：基于 `asyncio.Semaphore` 实现精细化的并发限频，在满足高吞吐量的同时，确保严格符合 Tushare/Akshare 等 API 的访问频率限制。
* **状态机管理**：使用 `DataSource` DataClass 定义任务生命周期，实现“检查 -> 校验 -> 下载 -> 二次校验”的闭环逻辑。
* **容错与重试**：内置指数退避重试机制，针对金融 API 常见的网络波动和频率限制（HTTP 429）进行了健壮性处理。

### 2. LLM 驱动的金融数据清洗 (NLP in Finance)
* **语义对齐**：针对 A 股上市公司主营业务描述（非标字符串）不统一的问题，集成 **阿里通义千问 (Qwen-Plus)** 接口，通过 Prompt Engineering 将数千种业务类型自动归类至标准中证三级行业分类。
* **健壮解析**：利用 `json_repair` 与正则提取技术，解决了大模型输出 JSON 格式不稳定的痛点，确保了自动化管线的端到端执行。

### 3. 工程化数据治理
* **多维覆盖**：整合了日线行情、PE/PB 估值、分红送配、主营业务构成（主音）及股票更名历史等核心量化维度。
* **增量更新逻辑**：通过解析本地序列化文件（Pickle/CSV）获取最新 Timestamp，仅对缺失数据进行补丁式抓取，极大地节省了带宽和 API 积分。
* **自动化备份系统**：内置自动时间戳归档机制（Zip 压缩），确保数据在中转与生产环境切换过程中的安全性。
